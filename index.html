The Process

The Process

  1. Installed the BlenderGIS add-on (github.com/domlysz/BlenderGIS). In Blender: Edit → Preferences → Add-ons → Install from Disk, then enabled it.
  2. Got a free API key from OpenTopography (opentopography.org) and added it to BlenderGIS to access elevation data.
  3. Loaded a basemap: GIS → Web geodata → Basemap, searched each mountain with G, zoomed to the area, and pressed E to export the satellite imagery as a plane.
  4. Added elevation: GIS → Web geodata → Get elevation, using Copernicus GLO-30 (30 m) data. The default SRTM dataset only covers 60°N to 56°S, so it has no data for Denali or Vinson.
  5. Corrected Web Mercator distortion by scaling X and Y by cos(latitude), so every tile shows true ground distance. The map stretches land sideways away from the equator: about 2.2× at Denali and 5× at Vinson.
  6. Set the Z scale to 1.7 (vertical exaggeration), the same for all seven so they stay comparable.
  7. Cropped each mountain to a 17 × 17 km square centered on the summit:
    • Shift + A → Mesh → Cube, sized 17000 × 17000 × 30000
    • Added a Boolean modifier to the terrain: Intersect, Exact solver, Hole Tolerant
    • Applied it, deleted the cube, and saved
  8. Packed resources (File → External Data → Pack Resources), applied modifiers and transforms, and exported each mountain as a .glb file for the web.
